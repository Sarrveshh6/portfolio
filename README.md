# Full-Stack Developer Portfolio

Premium personal portfolio built from `PORTFOLIO_PRD.md` — React, Vite, Tailwind CSS, Framer Motion.

## Quick start

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Customize

1. Edit `src/data/personal.js` — name, links, copy
2. Edit `src/data/projects.js`, `experience.js`, `certifications.js`
3. Add resume PDF to `public/resume/`
4. Copy `.env.example` → `.env` and add EmailJS keys for the contact form

## Scripts
